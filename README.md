# Hemapathi — Developer Portfolio

A modern, fully responsive personal portfolio built with React and Vite. Features smooth page transitions, interactive UI components, and a clean design system with light/dark mode support.

---

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | React 18 + Vite 6 |
| Animations | Framer Motion 12 |
| Styling | CSS3, Tailwind CSS |
| Icons | React Icons |
| Email | EmailJS |
| Deployment | Netlify |

---

## Features

- Light / Dark mode with persistent theme
- Smooth page-to-page transitions with custom loaders
- YouTube-style skeleton loading on the Work page
- Interactive certifications (flip cards / badge wall)
- Skill tree with proficiency levels
- EmailJS contact form with validation
- Fully responsive — mobile & desktop layouts
- Dynamic Island mobile navigation

---

## Pages

| Page | Description |
|---|---|
| Hero | Introduction with animated text |
| About | Bio, quick facts, and stats |
| Skills | Tabbed skill view with progress bars |
| Certifications | Interactive badge/card display |
| Work | Project showcase with skeleton loader |
| Contact | EmailJS-powered contact form |
| Resume | ATS-friendly resume with download |

---

## Getting Started

```bash
# Clone the repo
git clone https://github.com/hemahemapathi/minimal-portfolio.git
cd minimal-portfolio

# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```

Dev server runs at `http://localhost:3001`

---

## Deployment

This project is configured for Netlify.

- Build command: `npm run build`
- Publish directory: `dist`
- SPA redirects handled via `netlify.toml` and `public/_redirects`
